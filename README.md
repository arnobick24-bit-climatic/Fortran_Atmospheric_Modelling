# Fortran_Atmospheric_Modelling
This repository contains Fortran codes that reperesents various typrs of atmospheric models which are the basic for Atmospheric/ Climatic sciences research.

The zero-layer atmospheric radiation balance model represents the Earth–atmosphere system as a single, spatially averaged control volume in radiative equilibrium. Incoming solar radiation is partially reflected by the planetary albedo, while the absorbed energy is balanced by outgoing thermal infrared radiation emitted according to the Stefan–Boltzmann law.

The one-layer atmospheric radiation balance model has been created by making some important assumptions:
  1) The atmosphere is a one-layer homogenous system.
  2) It is fully transparent to Short-Wave radiation, but absorbs and re-emits the longwave Infrared radiation back to the surface, simulating a Green-House effect.
  3) The scattering effect by various atmospheric aerosol species is neglected.

Both the models have been modeled in Fortran.
